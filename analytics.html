How Traffic is Measured & Classified

1. The Core Principle: Human Sessions ≠ AI Crawler Requests

Traditional web analytics (like Google Analytics) rely on browser JavaScript. AI crawlers (GPTBot, ClaudeBot, PerplexityBot) do not execute JavaScript. They make direct HTTP GET requests, parse the raw HTML or data.json, and exit.

2. Edge-Level Detection (Cloudflare Proxy)

Because all traffic is routed through Cloudflare edge proxy, every request is inspected before the page is served. We classify requests into two streams:

  • Human Visitors: Verified browser user-agents with JavaScript rendering and full DOM navigation.
  • AI Crawlers & Search Bots: Verified bot tokens matching known AI platforms:
    • GPTBot / OAI-SearchBot / ChatGPT-User (OpenAI)
    • ClaudeBot / Claude-SearchBot (Anthropic)
    • PerplexityBot / Perplexity-User (Perplexity AI)
    • Google-Extended / GoogleOther (Gemini / Vertex)
    • Bytespider / Meta-ExternalAgent / CCBot

3. Data Freshness & Updating

Our autonomous research engine runs every 2 hours, querying the Cloudflare GraphQL Analytics API, updating stats.json, and deploying fresh counts to this page automatically.
